Validation과 K-Fold의 차이점

✅ Validation (검증)
의미: 데이터셋을 훈련(train) / 검증(validation) / 테스트(test) 로 나누었을 때,
모델이 학습되지 않은 데이터를 가지고 성능을 중간 점검하는 과정이에요.

방법:
예를 들어 전체 데이터가 1000개라면,
700개 → 학습(train)
200개 → 검증(validation)
100개 → 테스트(test)
이런 식으로 나눠서 검증셋으로 학습 도중 과적합 여부, 하이퍼파라미터 적합성 등을 평가하는 거예요.

특징:
검증 데이터는 고정되어 있음 (랜덤하게 한 번 분리하거나, 특정 비율로 유지).
빠르고 단순하지만, 데이터 수가 적을 경우 검증 결과가 불안정할 수 있음.

✅ K-Fold Cross Validation (교차 검증)
의미: 데이터를 K개로 나눈 뒤, 그 중 1개를 검증(validation)으로 쓰고 나머지 K-1개를 학습에 사용. 이걸 K번 반복해서 평균 성능을 내는 방법.

예시 (K=5일 때):
데이터 1000개 → 200개씩 5개 그룹으로 나눔
1번 그룹: 검증 / 2~5번 그룹: 학습
2번 그룹: 검증 / 1,3~5번 그룹: 학습
…
5번 그룹: 검증 / 1~4번 그룹: 학습
→ 성능 5개가 나오고, 그 평균이 최종 모델의 안정적인 성능 추정치가 됨.

특징:
데이터를 최대한 효율적으로 사용 (모든 샘플이 한 번은 검증에, 여러 번은 학습에 쓰임).
데이터가 적을 때 특히 유용.
계산량이 늘어남 (모델을 K번 학습해야 하니까).
